# Sales & Customer Analytics using SQL

## Overview
This project demonstrates SQL-based data analysis using the Chinook digital music store database. The objective was to answer real-world business questions by querying relational data and extracting meaningful insights related to customers, sales, revenue, artists, and music genres.

## Objectives
- Analyze customer purchasing behavior
- Identify top-selling artists and genres
- Evaluate sales and revenue trends
- Perform country-wise and customer-wise analysis
- Practice advanced SQL for business analytics

## Tools & Technologies
- PostgreSQL
- SQL

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- INNER JOIN
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Recursive CTEs

## Business Questions Solved
- Identify the senior-most employee.
- Find countries with the highest number of invoices.
- Determine the city generating the highest revenue.
- Identify the highest-spending customers.
- Analyze Rock music listeners and top Rock artists.
- Find tracks longer than the average song length.
- Calculate customer spending by artist.
- Identify the most popular music genre by country.
- Determine the highest-spending customer in each country.

## Key Outcomes
- Extracted actionable insights from a relational database using SQL.
- Performed customer, sales, and revenue analysis.
- Built complex analytical queries involving multiple related tables.
- Strengthened SQL skills for real-world data analytics applications.
